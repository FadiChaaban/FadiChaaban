### 🌟 Featured Projects

#### 1. [Optimal Site Selection Analysis in QGIS 3.44 LTR (`qgis-optimal-site-suitability`)](https://github.com/FadiChaaban/qgis-optimal-site-suitability)
- **Overview:** Complete modernization and automation of a multi-criteria spatial suitability workflow (Chaaban & Darwishe, 2017) using **QGIS 3.44 LTR** with **zero external dependencies** (no SAGA or GRASS required).
- **Key Features:** Graphical Modeler (`.model3`) + standalone **PyQGIS** `QgsProcessingAlgorithm` featuring automatic DEM grid detection, metric CRS validation, dynamic normalized weights, an iterative **3×3 Majority Filter in pure NumPy/GDAL**, and automated vector extraction (`area_ha`).
- **Tech Stack:** Python, PyQGIS, GDAL, NumPy, Sentinel-2, QGIS Processing.
